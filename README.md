AI Student Study Assistant

Project Description

AI Student Study Assistant is a web application designed to help students improve their learning experience. It provides study planning, concept explanations, notes summarization, quizzes, learning resources, and daily motivation.

Features

- Study Planner
- Concept Explainer
- Notes Summarizer
- Quiz Arena
- Learning Resources
- Daily Motivation
- Light/Dark Mode

Technologies Used

- HTML
- CSS
- JavaScript
